### F08-2 Behaviours
| ID | Behaviour (binding once approved) | Implements |
|---|---|---|
| BEH-REV-01 | **Exception queue view** (`OP-REV-01`, HTML + JSON). Lists every item whose current outcome has a queue (quarantine_invalid, revision_review, unmatched, ambiguous_match, flagged_value): `reason_code` (primary + all), `queue`, `source`, `receipt_time`, `age` (now - receipt_time, computed at request, in hours), matched case if any, `flag_id`. Excludes `NOOP_DUPLICATE`. Filters: queue, reason, source, age >= N; default sort age descending then `raw_id`; `limit` default 50, max 100 (clamp, `next` cursor). Every quarantined/unmatched item appears in exactly one queue. Item text is shown escaped with an 'untrusted source text' marker. | FR-REV-02 |
| BEH-REV-02 | **Rule-trace explanation** (`OP-REV-02`): for a triage outcome (F03) the page renders a text produced by a versioned template (`trace_template`) from the stored trace fields only: rule set name+version, each examined row id, the actual input values compared, which row matched, the outcome, and the `defaulted` marker/reason if set. The same stored inputs regenerate byte-identical text. Values outside the declared domain are shown escaped. The explanation is not generated by a model and contains no advice. Each explanation shows the override/dismiss/refuse action (F02). | FR-REV-01, PNFR-15 |
| BEH-REV-03 | **(R2) Search** (`OP-REV-03`). Index `doc_index` (FTS5) over documents and archive items, whole-document rows, no chunking while a document is <= configured size. Query grammar is fixed: whitespace-separated terms (implicit AND), double-quoted phrases, field filters `ref:`, `doc:`, `locale:`, `version:`, `from:` and `to:` (effective date, ISO). Maximum query length 200 characters and 12 terms; unknown field or malformed filter -> E-REV-QUERY-INVALID. User text is never passed raw to `MATCH`: every term is quoted/escaped and parameters are bound (operators `OR`, `NOT`, `NEAR`, `*`, `:` have no effect). | FR-REV-03 |
| BEH-REV-04 | **Search authorisation and ranking.** The `access_level` / tenant / role filter is applied inside the query before ranking and counting; totals never include denied rows. Rank = `bm25()`, ties by `effective_at` descending then `doc_id`; no reranker, no randomness. Default shows all versions with dates; `latest_only=true` collapses versions per `reference`. The trigram index is used for ja-JP and substring/ID search. NULL `ocr_confidence` is shown as 'unknown', values < 0.70 flagged, never hidden. Each hit shows doc_id, version, effective date, source, locale, access label, hash prefix, escaped `snippet()`, 'untrusted source text' marker, and the linked case if the crosswalk has one, else 'no linked case'. | FR-REV-03, FR-SEC-03, PNFR-13 |
| BEH-REV-05 | **No generation.** The search and queue endpoints return stored text and metadata only; no summary, answer, rewritten query, synonym expansion or recommendation exists in any response (FR-CO-04). Planted instruction strings are findable as ordinary text and are labelled; they influence nothing but text relevance. | FR-REV-03, FR-CO-04, PNFR-18 |
| BEH-REV-06 | **FTS5 availability.** At start-up the product tests `CREATE VIRTUAL TABLE ... USING fts5` and `trigram`; if unavailable it logs the fact, sets `search.engine = fallback` (LIKE / Python inverted index, same grammar and same result order) and reports the engine in `OP-REV-03` responses. Dev device: SQLite 3.37.2 with FTS5 + trigram verified; target runtime is Unknown (OD-S12-12). | FR-REV-03 |
| BEH-REV-07 | **(R2, Could) Template form.** `OP-REV-04` serves a structured form for deviation/CAPA narrative fields (labels, field types, length limits) and stores drafts owned by the author. The product never pre-fills narrative content from rules, search or intake; submission/signature of the final record happens outside the product (T4); the draft carries no Zone H power. Deferred by default (candidate for Rejected at FINAL if no stakeholder asks). | FR-REV-04 |
| BEH-REV-08 | **Latency measurement.** Queue and search calls emit duration timers (F-observability) so p50/p95 on the 125-case baseline can be reported (PNFR-06, target Unknown - OPD-14). | PNFR-06 |
